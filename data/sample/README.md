# Sample data: made-up numbers

**Every number in this folder is synthetic.** None of it is real Regiwock data. It exists so the API and dashboard can be built and demoed before real analytics are connected in Phase 4. Real data goes in `data/real/`, which git ignores.

The files are generated by [`scripts/generate-sample-data.mjs`](../../scripts/generate-sample-data.mjs). Don't edit them by hand. Change the script and run:

```bash
npm run sample-data
```

The output is deterministic. A fixed random seed and a fixed end date (2026-09-30) mean every run writes identical files.

## Files

- `audience.csv`: `date, platform, audience`. 180 days (2026-04-04 to 2026-09-30) × 5 platforms = 900 rows. Spotify is monthly listeners. The other platforms are followers or subscribers.
- `content.csv`: `published_date, platform, content_type, title, views`. 212 releases, videos, streams, and shorts. Views are streams for releases, views for videos and shorts, and peak viewers for streams. Some titles contain commas and quotes, so they are quoted the standard CSV way (RFC 4180).

## Built-in breakouts

Six pieces of content get several times their platform's usual views. Each one adds a wave of new followers over the following week, so the growth chart visibly bends after it. Normal posts never go above 1.8× usual views, so these six are the only items that cross the default 2.5× breakout line.

| Date | Platform | Title | Extra followers it brings |
|---|---|---|---|
| 2026-05-14 | TikTok | POV: you hum a melody and I finish the song | +2,600 TikTok, +400 Spotify |
| 2026-07-08 | Kick | Album listening party, every track, no skips | +350 Kick |
| 2026-07-26 | Spotify | Glass Houses | +3,200 Spotify, +300 TikTok |
| 2026-08-10 | YouTube | I made a beat using only subway sounds | +900 YouTube |
| 2026-09-02 | Twitch | 24-hour charity stream, part 1 | +650 Twitch |
| 2026-09-15 | TikTok | Fan duet: "Glass Houses", acoustic | +1,900 TikTok, +600 Spotify |

What the dashboard should show from this data: the 30-day view has 2 breakouts (Spotify is skipped because it has only 1 release in that window, under the 3-item minimum), the 90-day view has 5, and the 180-day view has all 6.
